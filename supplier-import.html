קטלוג ספקים

מייבאים כאן מחירון (CSV) שהורדתם מאתר הספק (מחוברים לחשבון הסוחר שלכם), ואז מחפשים מוצר לפי מק"ט/שם ומוסיפים אותו לקטלוג המכירה עם לחיצה אחת — המחיר יתמלא אוטומטית כעלות, וחשבון הרווחיות יחשב לפניכם את מחיר המכירה.

ייבוא מחירון חדש

מוריד תמיד את "הורדת מחירון" מאתר מור לוי לתיקיית Mor-Levi שבתיקיית התוכנה (או שולחים לי את הקובץ ואני שם אותו שם) — הכפתור הזה תמיד ימצא וייבא את הקובץ העדכני ביותר שם, גם אם שם הקובץ משתנה בכל הורדה. (עובד רק כשמריצים דרך "מערכת הצעות מחיר.exe").
