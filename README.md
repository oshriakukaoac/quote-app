# מערכת הצעות מחיר – OAC

תוכנה עצמאית ליצירת הצעות מחיר בעברית, בכיוון ימין־לשמאל. רצה כולה בדפדפן, בלי צורך בהתקנת Python/Node/שרת — כל הנתונים נשמרים בדפדפן עצמו (localStorage).

## איך מריצים

לחיצה כפולה על **`מערכת הצעות מחיר.exe`**. זה קובץ הרצה אמיתי (EXE) — בלי חלון קונסולה, בלי PowerShell גלוי. הוא:
- פותח את התוכנה אוטומטית בדפדפן (`http://localhost:8080`)
- מוסיף סמל קטן באזור השעון (system tray) — לחיצה ימנית עליו נותנת "פתיחת התוכנה בדפדפן" ו"סגירת התוכנה". **כדי לסגור את התוכנה**, לוחצים ימני על הסמל ובוחרים "סגירת התוכנה" (סגירת חלון הדפדפן בלבד לא מכבה את השרת).
- מאפשר גם את כפתור "שלח ל-Finbot" (הוא זה שמדבר בפועל עם Finbot, כדי לעקוף חסימת CORS של הדפדפן).

אין צורך בהתקנות — זו תוכנת exe עצמאית שנבנתה מקוד המקור שנמצא ב-`server-src\Program.cs` (בעזרת המהדר של NET. שכבר קיים בכל Windows).

> **חשוב:** תמיד תפתחו את התוכנה **רק** דרך `מערכת הצעות מחיר.exe` (לא ע"י פתיחה ישירה של `index.html`). לדפדפן יש אחסון נתונים נפרד לכל "כתובת" — פתיחה ישירה של הקובץ ופתיחה דרך `http://localhost:8080` הן שתי כתובות שונות עם נתונים נפרדים לגמרי! אם בטעות הצטברו לכם נתונים בשתי הדרכים ורוצים לאחד — במסך [הגדרות](settings.html) יש "ייצוא כל הנתונים לקובץ גיבוי" ו"ייבוא מקובץ גיבוי" בדיוק בשביל זה.

## מה יש בפנים

- **לוח בקרה** (`index.html`) — סטטיסטיקות והרשימת הצעות אחרונות.
- **לקוחות** (`customers.html`) — ניהול כרטיסי לקוח, כולל ייבוא מרשימת לקוחות ב-Finbot (`customer-import.html`).
- **קטלוג מוצרים** (`products.html`) — מוצרים ושירותים, כולל **מחשבון רווחיות**: מזינים מחיר עלות לפני מע"מ, המערכת מציגה מיד מחיר כולל מע"מ, מחיר מכירה מומלץ לפי אחוז רווח (ברירת מחדל 30%, ניתן לשינוי לכל מוצר), ומחיר סופי ללקוח כולל מע"מ. לכל מוצר יש גם שדות טקסט שיווקי (כותרת, תיאור, מפרט, קהל יעד, שורת סיכום) שמשמשים גם בהצעת המחיר וגם בהודעת הוואטסאפ. אפשר לסמן מוצר כ"⭐ מועדף" — יופיע כקיצור דרך מהיר במסך הצעת המחיר.
- **הצעת מחיר** (`quote.html`) — בחירת לקוח (עם חיפוש והשלמה אוטומטית), הוספת פריטים: חיפוש והשלמה אוטומטית מהקטלוג, קיצורי דרך למוצרים מועדפים (⭐), חיפוש ישיר ממאגר הספקים (מחיר מחושב אוטומטית לפי הרווח שהוגדר), או פריט חופשי; הנחה (אחוז/סכום), מע"מ, מספור אוטומטי רציף, שמירה כטיוטה או כהצעה סופית, שכפול הצעה קיימת, ומחיקה.
- **הפקת PDF** (`quote-print.html`) — עמוד הדפסה במראה מקצועי (לוגו, פרטי עסק, טבלת פריטים, סיכומים, הערות). לוחצים "הדפסה / שמירה כ-PDF" ובוחרים "Microsoft Print to PDF" (או Save as PDF) בחלון ההדפסה של הדפדפן.
- **הודעת וואטסאפ** (`whatsapp.html`) — בוחרים מוצר אחד או כמה מהקטלוג (עם אפשרות להוסיף/להוריד), ומקבלים הודעה שיווקית מוכנה להעתקה, עם אפשרות לכלול מחיר.
- **הגדרות** (`settings.html`) — פרטי העסק שמוצגים בהצעות, אחוזי מע"מ/רווח ברירת מחדל, ומספר ההצעה הבא.
- **מאגר ספקים** (`supplier-import.html`) — מייבאים קובץ מחירון (CSV/TSV, כל קידוד/מפריד) שהורדתם מאתר הספק (למשל "הורדת מחירון" באתר מור לוי, כשמחוברים לחשבון הסוחר). המערכת מזהה אוטומטית את העמודות (מק"ט/תיאור/מחיר/יצרן/קטגוריה/זמינות), מציגה תצוגה מקדימה, ושומרת הכול במאגר חיפוש נפרד (לא בקטלוג המכירה עצמו). מכל מקום בקטלוג (`products.html`) אפשר לחפש לפי מק"ט/שם ולמלא מוצר חדש בלחיצה — המחיר נכנס כעלות, ומחשבון הרווחיות מציע מיד מחיר מכירה.

בהרצה ראשונה המערכת נטענת עם נתוני דוגמה אמיתיים (העסק שלך, לקוח לדוגמה, קטלוג עם המוצרים מהדוגמה, והצעת מחיר 80156 המשוחזרת) — כדי שתוכל לראות מיד איך הכול עובד. ניתן לאפס הכול מ"הגדרות".

## ייבוא לקוחות מ-Finbot

ב[לקוחות](customers.html) יש כפתור "ייבוא לקוחות מ-Finbot". ב-Finbot: הכנסות ← לקוחות ← "ייצוא" (מוריד קובץ Excel). מעלים את הקובץ ב[מסך הייבוא](customer-import.html), בודקים את התאמת העמודות (מזוהה אוטומטית), ומייבאים. לקוח קיים עם אותו שם מתעדכן במקום להשתכפל — כך שאפשר לייבא מחדש בכל פעם שרוצים לרענן, בלי לדאוג לכפילויות.

התוכנה קוראת קבצי Excel (.xlsx) ישירות בדפדפן, בלי שום ספרייה חיצונית (`js/xlsx-mini.js`) — נבדק בפועל מול קובץ אמיתי של 257 לקוחות.

## אינטגרציית Finbot (הנהלת חשבונות)

בהצעת מחיר יש כפתור "שלח ל-Finbot" שיוצר את אותה הצעה ישירות ב-Finbot (כ"הצעת מחיר" רשמית שם), דרך ה-[API המתועד של Finbot](https://finbot.helpjuice.com/he_IL/api-docs-create-income).

**חשוב:** Finbot חוסם קריאה ישירה מהדפדפן ל-API שלהם (CORS) — נבדק בפועל. לכן חובה להריץ את התוכנה דרך **`מערכת הצעות מחיר.exe`** (ולא ע"י פתיחת `index.html` ישירות) — ה-EXE הזה גם משמש "מתווך": הדפדפן פונה אליו (אותו מקור, אין חסימת CORS), והוא זה שקורא בפועל ל-Finbot מהצד שלו (קריאת שרת־לשרת, לא כפופה ל-CORS).

במסך [הגדרות](settings.html) מדביקים מפתח API (מ-Finbot: הגדרות עסק ← מפתח API להפקת הכנסות). המפתח נשמר רק בדפדפן שלכם, ולא נשלח לשום מקום מלבד Finbot עצמה.

אם פותחים את `index.html` ישירות (בלי ה-EXE) — כל שאר התוכנה עובדת רגיל, רק כפתור "שלח ל-Finbot" יציג הודעה שמסבירה שצריך להפעיל את `מערכת הצעות מחיר.exe`.

**עובד בפועל (נבדק עם מפתח אמיתי):** ✅ עובד ומייצר הצעת מחיר אמיתית ב-Finbot.

**דברים חשובים שלמדנו תוך כדי בדיקה אמיתית:**
- **תוסף אבטחה/מנהל סיסמאות בדפדפן** (כמו Guardio, מזהה לפי קובץ בשם `guard.min.js`) יכול לחסום בשקט את הקריאה המקומית ל-`/api/finbot/income`, בלי הודעת שגיאה ברורה בדפדפן. אם "שלח ל-Finbot" נכשל עם "שגיאת רשת מול השרת המקומי" — נסו קודם בחלון גלישה בסתר (שם תוספים כבויים כברירת מחדל) כדי לוודא שזה התוסף, ואז הוסיפו חריגה עבור `localhost:8080` בתוסף עצמו.
- שדה `language` חייב להישלח כ-`"HE"`/`"EN"` (אותיות גדולות) — התיעוד המילולי של Finbot כתוב לא נכון (`he`/`en`), אבל ה-Swagger הרשמי שלהם מגדיר אותיות גדולות בלבד.
- **`customer.save` נשלח כ-`false` בכוונה** — בבדיקה, שליחה עם `save: true` (כמו שהתיעוד ממליץ) גרמה ל-Finbot לשייך את המסמך ל**לקוח קיים שגוי** אצלם (כנראה "התאמה חכמה" באגית לפי שדות ריקים). לכן האינטגרציה לא נוגעת בכלל בכרטיסי הלקוחות ב-Finbot — רק מציינת את השם על גבי המסמך. ניהול כרטיסי הלקוחות נשאר דרך הייבוא התקופתי מ-Excel (ראו למעלה) או ידנית ב-Finbot עצמו.
- לפני כל שליחה מוצגת בקשת אישור עם שם הלקוח והסכום — לבדוק תמיד שהלקוח נכון לפני אישור, כי הפעולה יוצרת מסמך אמיתי ב-Finbot (אין להם API למחיקה — ביטול/מחיקה של מסמך שגוי נעשים ידנית בממשק שלהם).

**קובץ גיבוי (`serve.ps1`):** יש גם גרסה ישנה מבוססת PowerShell (עם חלון קונסולה גלוי) שנשארה בתיקייה למקרה חירום — לא נדרשת לשימוש רגיל.

## חיבור לספקים (מור לוי / CDATA)

**מור לוי:** באתר יש כפתור "הורדת מחירון" (גם בלי התחברות) שמאפשר לבחור קטגוריות ולייצא Excel/CSV. מורידים אותו כשמחוברים לחשבון הסוחר (כדי לקבל מחירים אמיתיים).

**טעינה אוטומטית (בלי להקליד שם קובץ):** שמים את קובץ המחירון בתיקיית `Mor-Levi\` שבתוך תיקיית התוכנה (השם משתנה בכל הורדה — לא משנה). ב[מאגר ספקים](supplier-import.html) לוחצים על **"📂 טעינה וייבוא אוטומטיים מתיקיית Mor-Levi"** — המערכת מוצאת לבד את הקובץ העדכני ביותר בתיקייה (דרך ה-EXE) ומייבאת אותו במלואו בלחיצה אחת. עובד רק כשמריצים דרך `מערכת הצעות מחיר.exe` (לא בפתיחה ישירה של `index.html`). נבדק בפועל מול קובץ אמיתי (1,761 שורות) — עובד מצוין.

**CDATA:** אין כפתור ייצוא גלוי באתר; צריך חשבון סוחר מאושר (יש טופס "בקשה לפתיחת כרטיס לקוח" באתר) ולברר מול נציג הלקוחות איזה קובץ/גישה הם נותנים לסוחרים. אותו מסך "מאגר ספקים" יעבוד גם עבורם — צריך רק קובץ דוגמה כדי לוודא שהעמודות מזוהות נכון.

**מה שלא נבנה בכוונה:** גרידה אוטומטית/מתוזמנת שדורשת החזקת סיסמת הסוחר שלך בתוכנה. זה גם שביר (נשבר בכל שינוי אתר) וגם לא נכון מבחינת אבטחה. הזרימה תמיד: אתה מתחבר ומוריד את הקובץ בעצמך → מעלה אותו לתוכנה.

## מה עוד נשאר לשלב הבא (לא כלול בגרסה זו)

- שמירה מרכזית/שיתוף בין כמה מחשבים (כרגע כל דפדפן שומר נתונים בנפרד).
- העלאת לוגו אמיתי כתמונה (כרגע לוגו טקסטואלי "OAC").
